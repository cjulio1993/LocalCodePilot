# LocalCodePilot 1.0.0-alpha.1

**Seus projetos no centro.** Uma lista única com o estado de cada projeto e a próxima ação, e uma página por projeto com tudo sobre ele. Versão alpha para Windows 10/11 x64, com DMG universal experimental para Macs Intel e Apple Silicon.

É a primeira versão do caminho para a 1.0: `1.0.0-alpha` → `1.0.0-beta` → `1.0.0`.

**Qual arquivo baixar no Windows:** `LocalCodePilotSetup-1.0.0-alpha.1-windows-x64.exe`, o instalador (recomendado), ou o zip portátil. O arquivo `LocalCodePilot-1.0.0-alpha.1-windows-x64.exe` é usado pelo atualizador do app; aberto direto, ele não se atualiza sozinho.

## Novidades

- **Projetos é a tela inicial.** Uma lista em linhas, como uma tabela: Projeto, Estado (com o motivo), Endereço e a ação do momento à direita (**Parar** quando roda; senão **Iniciar**, **Instalar dependências** ou a correção). Filtros **Com problema**, **Rodando** e **Parado**, e a ordem não muda quando um projeto inicia ou para.
- **Página do projeto.** Clique no projeto para ver **Resumo**, **O que roda** (processos e containers, com porta e logs), **Banco de dados**, **Logs** e **Detalhes técnicos**.
- **Navegação mais simples.** A barra lateral tem **Projetos**, **Ambiente**, **Ajuda** e **Configurações**. A busca encontra projeto, serviço, porta ou container. **Ambiente** mostra o que o LocalCodePilot controla (Docker e Podman, que ligam ali mesmo com confirmação, e os bancos de dados) e o que ele só encontrou (outros containers e as linguagens).
- **Estados com quatro palavras:** Rodando, Parado, Iniciando e Com problema, sempre com o motivo por escrito. Quando o banco recusa o acesso, a página oferece **Ver detalhes técnicos** e **Testar conexão de novo**.
- **Iniciar faz mais sozinho:** liga o Docker ou o Podman quando estão parados (com confirmação); roda as migrations pendentes de projetos Laravel (com confirmação); compila e executa projetos C/C++ com CMake, Meson ou Visual Studio; roda Perl, Lua, R e Julia pelo arquivo de entrada; no Windows, oferece instalar o compilador C/C++ quando falta.
- **Diagnóstico:** **Detalhes técnicos** explica por que o projeto está naquele estado, e **Exportar diagnóstico** salva um arquivo para pedir ajuda, sem senhas, tokens ou caminhos pessoais.
- **Configurações mais seguras:** um arquivo de configuração ilegível não apaga mais seus favoritos, histórico e comandos; o app restaura a última cópia válida e avisa.
- **Depois de atualizar**, o aviso **LocalCodePilot atualizado para 1.0.0-alpha.1** mostra as novidades uma vez, também sem internet.
- **Acessibilidade:** contraste maior nos botões azuis, botões da lista que dizem o nome do projeto ao leitor de tela, foco do teclado visível e lista que se ajusta à janela estreita e ao zoom.

## Segurança

- A cópia do `.env` feita por **Usar outra porta** ficava na pasta do projeto e podia ir para o Git com a senha. Agora fica na pasta de dados do LocalCodePilot.
- Dependência `url` atualizada (RUSTSEC-2026-0592).

## Download e instalação

**Windows:**
- **Instalador:** baixe `LocalCodePilotSetup-1.0.0-alpha.1-windows-x64.exe`. O app é instalado em `%LOCALAPPDATA%\Programs\LocalCodePilot`, sem pedir administrador, com atalho no Menu Iniciar.
- **Zip (portátil):** extraia `LocalCodePilot-1.0.0-alpha.1-windows-x64.zip` e execute `LocalCodePilot.exe`.
- **Quem usa a Alpha 10:** o app avisa a nova versão; use **Atualizar agora**. Seus projetos, favoritos e configurações continuam.

**Antes de abrir, confira o arquivo.** Os arquivos desta versão **não têm assinatura de código**, e o Windows pode mostrar "O Windows protegeu o computador". Compare o SHA-256 do arquivo baixado com o publicado em `SHA256SUMS.txt` (`Get-FileHash -Algorithm SHA256 -LiteralPath '.\NOME-DO-ARQUIVO'`). Só se forem iguais, abra o arquivo e, no aviso, clique em **Mais informações** e depois em **Executar assim mesmo**.

**macOS (experimental):** baixe o DMG universal, confira o SHA-256 e arraste `LocalCodePilot.app` para `Applications`. O pacote usa assinatura ad hoc e não é notarizado. Veja o `README-MACOS.txt`.

## Limitações

- **macOS:** experimental. {PREENCHER COM O RESULTADO DO TESTE NO MAC: o que foi testado num Mac real e o que não foi.}
- **Bancos de dados:** o app não cria tabelas além das migrations do Laravel; projetos configurados só por `DATABASE_URL` ou por arquivos de Spring, Django e .NET ainda não são reconhecidos; o SQL Server é preparado só em container, e a imagem funciona só em computadores x64.
- **Containers:** o app não instala o Docker nem o Podman.
- **Linux:** há só testes automáticos; não há pacote.
- **Atualização pelo app:** continua experimental.
