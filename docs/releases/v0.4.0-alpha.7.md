# LocalCodePilot 0.4.0-alpha.7

Versão alpha para Windows 10/11 x64, com DMG universal experimental para Macs Intel e Apple Silicon.

## Novidades

- WordPress é reconhecido por seus arquivos de configuração ou pelo Composer. O diagnóstico lê o `DB_HOST` literal sem exibir credenciais; projetos com Compose são encaminhados para iniciar PHP e banco juntos em **Containers**.
- **Processos** mostra containers Docker e Podman existentes, em execução ou parados, com estado, portas, logs e ações para iniciar, parar ou reiniciar.
- Portas web publicadas no Compose e nos containers oferecem URLs candidatas para abrir no navegador.
- Cartões de projeto mostram a próxima ação e distinguem serviços ativos de uma aplicação com resposta HTTP saudável. Opções secundárias ficam em **Mais ações**.
- **Processos** e **Containers** abrem filtrados para o projeto selecionado no catálogo, com opção para voltar à lista completa.
- README e Ajuda integrada descrevem os fluxos atuais e a recuperação de falhas.

## Download e instalação

No Windows, baixe `LocalCodePilot-0.4.0-alpha.7-windows-x64.zip`, confira o SHA-256 em `SHA256SUMS.txt`, extraia todos os arquivos e execute `LocalCodePilot.exe`. O arquivo `.exe` separado serve à atualização integrada.

No macOS, baixe o DMG universal, confira o SHA-256 e arraste `LocalCodePilot.app` para `Applications`. O pacote usa assinatura ad hoc e não é notarizado. Consulte o `README-MACOS.txt` incluído no aplicativo.

## Limitações

- Docker ou Podman e o provedor Compose precisam estar instalados e em execução; o LocalCodePilot não instala nem inicia esses motores.
- O diagnóstico de banco confirma no máximo a disponibilidade da porta local. Ele não valida usuário, senha nem a existência do banco configurado.
- Uma URL publicada por container não prova que o site esteja respondendo. Use **Processos** para verificar HTTP e logs.
- Os novos fluxos desta alpha ainda precisam de validação interativa em Windows 10 e macOS. O pacote macOS é experimental.
