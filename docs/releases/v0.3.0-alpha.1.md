# LocalCodePilot 0.3.0-alpha.1

Esta é a primeira versão alpha pública do LocalCodePilot para Windows. Ela permite descobrir projetos locais, preparar dependências, iniciar ambientes e acompanhar processos sem precisar montar os comandos manualmente no terminal.

## Destaques

- Inicie ou pare todos os serviços detectados de um projeto com um clique.
- Instale dependências ausentes de Node.js, Rust, PHP/Composer e Python pela interface.
- Acompanhe logs ao vivo em um visualizador semelhante a um terminal.
- Veja diagnósticos e sugestões quando a instalação falhar.
- Abra automaticamente as URLs locais encontradas nos logs.
- Faça uma simulação isolada antes de aceitar uma migração assistida de Laravel legado.

## Download para Windows

Baixe `LocalCodePilot-0.3.0-alpha.1-windows-x64.zip`, extraia o conteúdo e execute `LocalCodePilot.exe`.

Requisitos:

- Windows 10 ou Windows 11, 64 bits;
- runtimes dos projetos que você pretende executar, como Node.js, PHP, Composer, Python ou Rust;
- Visual Studio Code é opcional.

O executável desta primeira alpha ainda não possui assinatura digital. O Windows pode exibir um aviso do SmartScreen. Confira a integridade do ZIP comparando seu hash com `SHA256SUMS.txt` antes de executá-lo.

No PowerShell:

```powershell
(Get-FileHash .\LocalCodePilot-0.3.0-alpha.1-windows-x64.zip -Algorithm SHA256).Hash
```

## Limitações conhecidas

- A versão é experimental e pode mudar entre alphas.
- A detecção de portas pelo sistema operacional e os logs persistentes ainda não estão prontos.
- O encerramento completo de árvores de processos fora do Windows ainda está em desenvolvimento.
- O aplicativo não instala runtimes que não existam na máquina.
- Migrações assistidas dependem das restrições e compatibilidades declaradas pelo próprio projeto.

Relate problemas pelo [GitHub Issues](https://github.com/cjulio1993/LocalCodePilot/issues).
