# LocalCodePilot 0.4.0-alpha.6 — Windows

Versão alpha para Windows 10 e 11 x64.

## Novidades

- Visão geral mais simples, com projetos usados recentemente, estado do ambiente e uma ação principal por cartão.
- Diagnóstico de bancos de dados do projeto, incluindo PostgreSQL, MySQL, SQL Server e SQLite. Servidores de banco permanecem sob gestão do usuário; o aplicativo apresenta o estado e orienta a recuperação.
- Health checks HTTP para serviços locais, com código de resposta, tempo de resposta e indicação de perda da porta.
- Operações de Docker Compose pela interface: validar, iniciar, consultar estado e logs, parar e construir imagens de Dockerfiles isolados. Cada operação exige confirmação e pode ser cancelada.
- Descoberta e diagnóstico de projetos feitos em segundo plano para manter a janela responsiva.
- Cache local do catálogo para exibir os projetos rapidamente enquanto a descoberta é atualizada em segundo plano.
- Cartões de projeto padronizados, com altura e posição das ações consistentes.

## Instalação

Baixe o ZIP para Windows x64, confira seu SHA-256 em `SHA256SUMS.txt`, extraia todos os arquivos e execute `LocalCodePilot.exe`. O executável separado no mesmo lançamento é usado pelo atualizador integrado.

## Limitações conhecidas

- O aplicativo não instala nem inicia Docker Desktop ou Podman. O motor precisa estar disponível antes de usar a aba Containers.
- Podman 6.1.4 e Compose passaram em `config`, `up`, `ps`, logs e `stop` pela interface no Windows 11; build passou pela CLI. A validação no Windows 10 permanece pendente.
- O executável poderá ser distribuído sem assinatura Authenticode; nesse caso, o Windows pode mostrar um aviso do SmartScreen.
- macOS e Linux não fazem parte desta publicação.

O pacote e os fluxos principais foram validados no Windows 11 x64. A validação interativa em Windows 10 permanece pendente.
