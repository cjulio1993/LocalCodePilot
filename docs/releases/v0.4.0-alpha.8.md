# LocalCodePilot 0.4.0-alpha.8

**Clique em Iniciar e o projeto sobe.** Versão alpha para Windows 10/11 x64, com DMG universal experimental para Macs Intel e Apple Silicon.

## Novidades

- **Mais linguagens iniciam sozinhas.** Agora iniciam sem pedir comando:
  - .NET (ASP.NET, Blazor, console e soluções `.sln`);
  - Ruby (Rails, Rack, Sinatra);
  - Deno;
  - Kotlin (Ktor e Spring Boot);
  - Elixir (Phoenix);
  - Swift;
  - Scala (sbt);
  - Clojure (`deps.edn`);
  - Haskell (Stack);
  - Zig.

  Elas se somam a Node.js, PHP, Python, Java, Go, Rust, Dart e Flutter.
- **O app instala a linguagem que falta.** Quando o computador não tem o que o projeto precisa, o cartão mostra **Preparar ambiente**, que instala pelo winget depois da sua confirmação. A instalação foi validada de ponta a ponta com Clojure (Babashka), Haskell (Stack, com o compilador GHC) e Zig.
- **Projetos sem framework também iniciam:** um `Main.java`, uma pasta de páginas PHP, um site HTML ou um jogo em JavaScript.
- **Tentar de novo.** Depois de uma falha, como uma porta ocupada ou um programa que fechou, o cartão mostra o motivo e um botão para tentar outra vez.
- **Containers.** O Podman foi validado de ponta a ponta. No aviso de conflito de nomes do Compose, **Parar containers do outro projeto** para só os containers listados, sem apagar dados.
- **Mais confiável no Windows:**
  - linguagens instaladas fora do PATH passam a ser encontradas;
  - um programa instalado com o app aberto é encontrado sem reiniciar;
  - outro programa que divide a porta com o projeto aparece como porta ocupada;
  - **Abrir no VS Code** não cai mais no modo restrito.
- **Instalador para Windows**, ao lado do zip.
- **README reescrito** para quem está chegando.

## Download e instalação

**Windows:**
- **Instalador:** baixe `LocalCodePilot-0.4.0-alpha.8-windows-x64-setup.exe` e execute. O app é instalado em `%LOCALAPPDATA%\Programs\LocalCodePilot`, sem pedir administrador, com atalho no Menu Iniciar.
- **Zip (portátil):** extraia `LocalCodePilot-0.4.0-alpha.8-windows-x64.zip` e execute `LocalCodePilot.exe`.
- **Quem usa a Alpha 7:** baixe o instalador ou o zip da Alpha 8. O botão **Atualizar agora** da Alpha 7 não conclui essa atualização. A atualização pelo app continua experimental.
- **Integridade:** confira o SHA-256 em `SHA256SUMS.txt`.

Os arquivos desta versão **ainda não têm assinatura digital**, por isso o Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**.

**macOS (experimental):** baixe o DMG universal, confira o SHA-256 e arraste `LocalCodePilot.app` para `Applications`. O pacote usa assinatura ad hoc e não é notarizado. Veja o `README-MACOS.txt`.

## Limitações

- **Validação:** o início de cada linguagem foi validado de ponta a ponta no Windows 11. No macOS o pacote é experimental, e no Linux há só testes automáticos.
- **Bancos de dados:** Rails com banco ainda pede o `db:prepare` manual, e Phoenix com Ecto precisa de banco.
- **Formatos não cobertos:** projetos Leiningen (`project.clj`) e Haskell só com Cabal ainda pedem o comando de início.
- **Swift no Windows:** precisa do Visual Studio Build Tools com C++.
- **Containers:** o app não instala o Docker nem o Podman.
- **Atualização pelo app:** continua experimental até ser testada com uma versão mais nova.
