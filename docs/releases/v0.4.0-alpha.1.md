# LocalCodePilot 0.4.0-alpha.1

Esta alpha torna a execução de projetos locais mais previsível. O LocalCodePilot agora evita conflitos de porta, confirma quando cada serviço está realmente disponível, preserva o contexto entre sessões e passa a verificar novas versões em segundo plano.

## Destaques

- Detecta a porta esperada de servidores Laravel, Django, PHP, Vite, Next.js, React, Nuxt, Astro e webpack.
- Seleciona automaticamente a próxima porta livre quando o comando permite uma alteração segura.
- Mostra a porta escolhida na interface e nos logs.
- Identifica o processo e o PID que ocupam uma porta no Windows.
- Mantém o serviço como **Iniciando** até a porta ou URL ficar disponível.
- Detecta timeout, encerramento inesperado e perda da porta durante a execução.
- Sugere correções a partir dos erros encontrados nos logs.
- Reconhece listeners IPv4 e IPv6, incluindo servidores Vite em `::1`.
- Salva favoritos, projetos recentes, tela selecionada e projeto em foco.
- Preserva portas, URLs, resultados e as 200 linhas mais recentes de cada serviço.
- Permite retomar um ambiente e consultar os últimos logs depois de reabrir o aplicativo.
- Verifica uma vez por dia se existe uma nova release, incluindo versões alpha.

## Atualizações futuras

A partir desta versão, o LocalCodePilot consegue avisar quando uma nova versão estiver disponível. O aviso oferece acesso às novidades, ao download oficial e a opção **Lembrar depois**.

O aplicativo não baixa nem substitui o executável sozinho. Nesta fase, a atualização continua sendo instalada manualmente a partir do pacote publicado no GitHub. Usuários da versão `0.3.0-alpha.1` precisam fazer esta atualização manualmente uma vez, pois aquela versão ainda não possui o verificador.

## Download para Windows

Baixe `LocalCodePilot-0.4.0-alpha.1-windows-x64.zip`, extraia o conteúdo e execute `LocalCodePilot.exe`.

Requisitos:

- Windows 10 ou Windows 11, 64 bits;
- conexão com a internet apenas para verificar novas versões e abrir o download;
- runtimes dos projetos que você pretende executar, como Node.js, PHP, Composer, Python ou Rust;
- Visual Studio Code é opcional.

O executável ainda não possui assinatura digital. O Windows pode exibir um aviso do SmartScreen. Confira a integridade do ZIP comparando seu hash com `SHA256SUMS.txt` antes de executá-lo.

No PowerShell:

```powershell
(Get-FileHash .\LocalCodePilot-0.4.0-alpha.1-windows-x64.zip -Algorithm SHA256).Hash
```

## Privacidade e armazenamento local

- A verificação de atualização consulta a lista pública de releases do repositório no GitHub no máximo uma vez por dia.
- O LocalCodePilot não envia informações sobre seus projetos nessa consulta.
- Favoritos, histórico e logs ficam em `%APPDATA%\LocalCodePilot\workspace-state.json`.
- Nenhum processo salvo é reiniciado automaticamente ao abrir o aplicativo.

## Limitações conhecidas

- A versão é experimental e pode mudar entre alphas.
- O tratamento completo de árvores de processos fora do Windows ainda está em desenvolvimento.
- O aplicativo não instala runtimes ausentes na máquina.
- A atualização do próprio executável ainda é manual.
- Migrações assistidas dependem das restrições e compatibilidades declaradas pelo projeto.

Relate problemas pelo [GitHub Issues](https://github.com/cjulio1993/LocalCodePilot/issues).
