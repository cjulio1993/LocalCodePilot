# LocalCodePilot 0.4.0-alpha.10

**No Windows, Iniciar pode preparar o banco de dados do projeto.** No macOS e no Linux, o aplicativo testa a conexão com o banco de dados, mas não prepara o servidor. Versão alpha para Windows 10/11 x64, com DMG universal experimental para Macs Intel e Apple Silicon.

A Alpha 10 é a última versão alpha planejada do LocalCodePilot.

**Qual arquivo baixar no Windows:** `LocalCodePilotSetup-0.4.0-alpha.10-windows-x64.exe`, o instalador (recomendado), ou o zip portátil. O arquivo `LocalCodePilot-0.4.0-alpha.10-windows-x64.exe` é usado pelo atualizador do app; aberto direto, ele não se atualiza sozinho.

## Novidades

- **Banco de dados conectado de verdade.** O app testa o login com o banco, o usuário e a senha do próprio projeto (do `.env` ou do `wp-config.php`). O cartão só mostra **Banco de dados conectado.** depois desse teste; uma porta aberta não basta mais. Banco parado, acesso recusado e banco que não existe aparecem com o motivo por escrito.
- **Iniciar prepara PostgreSQL, MySQL e MariaDB (Windows).** Na primeira vez, a confirmação **Preparar banco de dados para este projeto?** mostra o download, o espaço necessário, o banco e o usuário que serão criados. O pacote é uma versão fixada e conferida por SHA-256, o servidor só escuta neste computador, e a senha de administração fica no Gerenciador de Credenciais do Windows. O projeto só inicia depois que o banco aceita os dados de acesso dele. Ao fechar o app, ele tenta encerrar o servidor e avisa na próxima abertura se não conseguiu; os dados permanecem.
- **Correções com confirmação.** Quando o banco impede o início, o cartão oferece a saída segura: **Usar outra porta** (muda só `DB_PORT` e guarda uma cópia do `.env`), **Corrigir conexão** ou **Criar banco novo** (os dados anteriores ficam guardados). Depois de cada correção, o login é testado de novo.
- **SQL Server.** O login do projeto é testado. No Windows, com o Docker ou o Podman prontos, **Iniciar** pode criar um container do SQL Server 2022 Developer, depois que você marcar que leu e aceita os termos de licença da Microsoft; o app nunca aceita por você. O preparo do SQL Server por container foi testado no CI em Linux com Docker. Ainda não foi testado de ponta a ponta no Windows (Docker Desktop ou Podman), nem a conexão com um SQL Server instalado direto no Windows.
- **Servidores que você já tem ficam intocados.** Um banco que já responde na porta do projeto só tem o login testado: nada é criado, alterado ou parado. Bancos do Compose continuam na página Containers.
- **Atualização pelo instalador oficial.** A partir da Alpha 10, uma cópia instalada passa a usar o instalador oficial nas próximas atualizações; a lista de programas do Windows acompanha a versão instalada. Uma janela pequena, **Atualizando o LocalCodePilot**, acompanha a instalação e o reinício.
- **Atualização mais clara:** a etapa **Instalar**, a pergunta antes de encerrar projetos em execução, erros em linguagem simples com a próxima ação e "O que há de novo" no aviso.
- **Projetos:** cards com a mesma altura, e a porta de outro programa não é mais atribuída a um projeto quando o Windows reaproveita o número de um processo.

## Download e instalação

**Windows:**
- **Instalador:** baixe `LocalCodePilotSetup-0.4.0-alpha.10-windows-x64.exe`. O app é instalado em `%LOCALAPPDATA%\Programs\LocalCodePilot`, sem pedir administrador, com atalho no Menu Iniciar.
- **Zip (portátil):** extraia `LocalCodePilot-0.4.0-alpha.10-windows-x64.zip` e execute `LocalCodePilot.exe`.
- **Quem usa a Alpha 8 ou a Alpha 9:** o app avisa a nova versão; use **Atualizar agora**. Na Alpha 9 instalada pelo instalador, a atualização troca só o executável, e a lista de programas do Windows continua mostrando a Alpha 9; para corrigir a lista, rode o instalador da Alpha 10 uma vez.
- **Quem usa a Alpha 7:** baixe o instalador ou o zip.

**Antes de abrir, confira o arquivo.** Os arquivos desta versão **não têm assinatura de código**, e o Windows pode mostrar "O Windows protegeu o computador". Compare o SHA-256 do arquivo baixado com o publicado em `SHA256SUMS.txt` (`Get-FileHash -Algorithm SHA256 -LiteralPath '.\NOME-DO-ARQUIVO'`). Só se forem iguais, abra o arquivo e, no aviso, clique em **Mais informações** e depois em **Executar assim mesmo**.

**macOS (experimental):** baixe o DMG universal, confira o SHA-256 e arraste `LocalCodePilot.app` para `Applications`. O pacote usa assinatura ad hoc e não é notarizado. Esta versão não foi testada num Mac real. Veja o `README-MACOS.txt`.

## Limitações

- **Bancos de dados:**
  - o preparo do servidor existe só no Windows;
  - o SQL Server é preparado só em container, e a imagem funciona só em computadores x64;
  - o app não cria tabelas: migrations como `db:prepare` (Rails) continuam com você;
  - projetos configurados só por `DATABASE_URL` ou por arquivos de Spring, Django e .NET ainda não são reconhecidos.
- **Atualização pelo app:** continua experimental.
- **Validação:** no macOS o pacote é experimental, e no Linux há só testes automáticos.
- **Containers:** o app não instala o Docker nem o Podman.
