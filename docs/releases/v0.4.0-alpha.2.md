# LocalCodePilot 0.4.0-alpha.2

Esta atualização corrige descoberta, preparação e acompanhamento de projetos no Windows.

## Correções

- Preparação com rolagem para revisar todos os requisitos e comandos, mantendo os botões acessíveis.
- Descoberta de projetos Java por Maven, Gradle e wrappers, mesmo sem JDK instalado.
- Execução e diagnóstico de npm e lançadores batch no Windows, sem selecionar scripts Unix por engano.
- Projetos Node sem dependências externas não exigem node_modules.
- Detecção do Dart embutido no Flutter e do SDK portátil instalado pelo winget.
- Pacotes já instalados sem atualização seguem para validação obrigatória do runtime.
- Aplicações de terminal que terminam com código 0 recebem o estado Concluído.
- Erros de preparação ficam registrados nos logs.
- Pastas com .localcodepilot-ignore ficam fora da descoberta recursiva do projeto pai.
- Detecção de Laravel/Lumen distingue os servidores corretos; Lumen usa o servidor PHP.
- Verificação SHA-384 do instalador do Composer funciona sem depender do PowerShell.

## Atualizar

Usuários de 0.4.0-alpha.1 recebem o aviso na próxima consulta diária de releases. Clique em Baixar atualização, feche o aplicativo, extraia o ZIP e use o novo LocalCodePilot.exe. A substituição ainda é manual.

Baixe LocalCodePilot-0.4.0-alpha.2-windows-x64.zip e confira o SHA-256 publicado em SHA256SUMS.txt.

## Validação e limites

73 testes do workspace aprovados, além de formatação, Clippy e build de produção. A preparação Java com JDK ausente também foi validada pelo usuário no Windows. Fixtures locais de QA não fazem parte do código publicado.

O aplicativo continua em alpha. A matriz completa em Windows 10/11 limpos permanece pendente. Docker/Podman e macOS continuam em desenvolvimento.

O pipeline pode publicar sem assinatura digital quando os segredos de assinatura não estão configurados.
