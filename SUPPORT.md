# Suporte / Support

O LocalCodePilot está em desenvolvimento inicial e ainda não oferece suporte comercial ou garantia de estabilidade.

- Use uma issue de bug para comportamentos reproduzíveis.
- Use uma solicitação de funcionalidade para propostas alinhadas ao produto.
- Nunca publique credenciais ou vulnerabilidades em uma issue; consulte [SECURITY.md](SECURITY.md).

LocalCodePilot is in early development and does not provide commercial support or stability guarantees yet.

- Use a bug report for reproducible behavior.
- Use a feature request for proposals aligned with the product.
- Never publish credentials or vulnerabilities in an issue; see [SECURITY.md](SECURITY.md).
